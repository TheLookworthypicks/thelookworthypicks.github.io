Privacy Policy

Effective Date: October 2026

1. Overview

This Privacy Policy explains how this personal Google Cloud OAuth application accesses and processes your data. This application is strictly for private, individual use to facilitate file transfers via the open-source software Rclone.

2. Data Access and Google Drive Scopes

This application requests access to your Google Drive via the following scopes:

  • .../auth/drive: Used to create, edit, download, and delete files on your Google Drive as requested through Rclone commands.
  • .../auth/docs: Used to manage Google Documents if selected for backup.
  • .../auth/drive.metadata.readonly: Used to read file sizes, modification dates, and folder structures to properly sync changes.

3. Data Storage and Third-Party Sharing

No data is collected, stored, or shared with third parties. All authentication tokens and file transfers remain local on your machine where Rclone is running. No external servers or remote telemetry are connected to this project.

4. Changes to This Policy

As a private project, this policy will only be updated if Google Cloud requirements change.
